# agent-lessons.md

Lessons the AI agent learned about how to work with you. These are workflow improvements, not facts about you. They exist so the agent does not repeat failed approaches.

## Format

```markdown
## <topic>

- **YYYY-MM-DD** — <trigger>: <what happened>
  - Wrong approach: <what the agent did>
  - Better approach: <what to do instead>
  - Why: <reason>
```

Group by topic. Create new topic sections as needed. Append; do not rewrite.
